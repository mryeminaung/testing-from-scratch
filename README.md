# Testing from Scratch

A hands-on journey into software testing, from fundamental concepts to practical QA techniques and test automation.

## About This Repository

This repository documents my learning journey in software testing and quality assurance (QA). It contains notes, practical exercises, test cases, bug reports, and automation examples as I develop my understanding of software quality.

## Learning Roadmap

- [ ] **01. Software Testing Fundamentals**
  - What is software testing?
  - Why testing matters
  - QA vs. QC vs. Testing
  - Verification vs. Validation
  - SDLC and STLC
  - Principles of software testing

- [ ] **02. Testing Types and Levels**
  - Unit, Integration, System, and Acceptance Testing
  - Functional vs. Non-functional Testing
  - Smoke, Sanity, and Regression Testing
  - Black-box, White-box, and Grey-box Testing
  - Exploratory and Ad-hoc Testing

- [ ] **03. Test Case Design**
  - Test scenarios and test cases
  - Test plans and test data
  - Positive and negative testing
  - Boundary Value Analysis
  - Equivalence Partitioning
  - Decision Table Testing

- [ ] **04. Bug Reporting and Test Documentation**
  - Writing clear bug reports
  - Severity vs. Priority
  - Reproduction steps
  - Expected vs. Actual Results
  - Test execution reports
  - Defect lifecycle

- [ ] **05. Web Application Testing**
  - UI and usability testing
  - Form validation
  - Authentication and authorization testing
  - Cross-browser and responsive testing
  - Accessibility fundamentals

- [ ] **06. API Testing**
  - HTTP methods and status codes
  - Request and response validation
  - Headers, query parameters, and request bodies
  - Authentication and authorization
  - Positive and negative API testing
  - Postman practice

- [ ] **07. Database Testing**
  - CRUD operations
  - Data integrity and constraints
  - SQL queries and validation
  - API-to-database consistency

- [ ] **08. Test Automation**
  - JavaScript and TypeScript testing fundamentals
  - Unit testing with Vitest
  - API testing with Supertest
  - End-to-end testing with Playwright
  - Assertions, fixtures, and test organization
  - Test automation best practices

- [ ] **09. Continuous Integration**
  - Running tests with GitHub Actions
  - Automated test execution on pull requests
  - Test reports and failure debugging
  - Quality checks in development workflows

- [ ] **10. Practical Projects**
  - Manual testing of a sample web application
  - API test collection
  - Automated UI test suite
  - Bug report and test case portfolio
  - CI-integrated testing project

## Learning Approach

For each topic, I aim to:

1. Understand the fundamental concepts.
2. Write concise notes and examples.
3. Practice with realistic testing scenarios.
4. Document test cases and defects.
5. Apply the concepts to practical projects.
6. Review and improve the tests based on feedback.
