# Exercise — QA vs. QC vs. Testing

**Lesson:** 03  
**Status:** Mini Challenge reviewed

## Classification Practice
| Activity | Main Classification | Reason |
|---|---|---|
| Pull Request Review Guidelines သတ်မှတ်ခြင်း | QA | Process Improvement |
| Registration API Automated Tests Run ခြင်း | Testing | Behavior ကို Execute/Check |
| Release Candidate ကို Acceptance Criteria နဲ့ Review | QC | Product Quality Evaluation |
| Requirements Review Checklist သတ်မှတ်ခြင်း | QA | Process Standardization |
| Unauthorized Approval API ကို Test လုပ်ခြင်း | Testing | Authorization Behavior Check |

## Mini Challenge
**Scenario:** Duplicate Email Bug ထပ်မဖြစ်အောင် Database Constraints Review Checklist သတ်မှတ်တယ်။

**Learner's Answer:**
> This is quality assurance because we need to define project requirement rules or guidelines before the development of a project.

**Review:** **QA — Correct.** Defect Prevention နဲ့ Process Improvement ဖြစ်တယ်။ QA က Development မစခင်တင် မဟုတ်ဘဲ SDLC တစ်လျှောက် လုပ်နိုင်တယ်။

## Key Distinction
- **QA:** Improve the process
- **QC:** Evaluate the product
- **Testing:** Execute and evaluate tests
