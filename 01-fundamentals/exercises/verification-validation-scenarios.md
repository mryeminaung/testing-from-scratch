## Notes
- Defined Specification ကို လိုက်နာမှု = Verification
- Actual User Needs/Intended Use ကို ဖြည့်ဆည်းမှု = Validation
- မူလ Requirements မှာ မပါသေးတဲ့ Need ကို Stakeholder နဲ့ Clarify လုပ်ပြီး Requirements/Design/Tests ကို Update လုပ်ရန် စဉ်းစားနိုင်တယ်။
